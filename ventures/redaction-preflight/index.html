Pre-release document check

Redaction Preflight

A black box is a drawing instruction, not a deletion. This reads the file the way an adversary would and tells you what is still recoverable.

  • Parsed on this device by an engine that ships with the page
  • No account, no upload, no logging
  • No network request carries any part of your document

What this checks. Text covered by an opaque shape or image; text drawn in an invisible render mode; reviewer comments and annotations; form-field values; earlier revisions left behind by incremental saves; embedded attachments and scripts; optional-content layers; bookmark labels; document metadata and embedded filesystem paths; and identifiers left in extractable text.

What it cannot tell you. It reads structure, not meaning. It cannot know whether a name is supposed to be in the document, and it will not recover text from a page that was genuinely flattened to an image without an OCR layer — which is also the one case where there is nothing left to recover. A clean result means no recoverable content was found by these checks, not that the document is fit to release. That judgement stays with you.

Where your file goes. Nowhere. The PDF engine is served from the same folder as this page, so your document is parsed in this tab and no request carrying any part of it is ever made. The page does fetch its two typefaces from Google Fonts on first load — that request happens before you choose a file and contains none of its content. Serve the fonts locally, or delete the stylesheet link, for an installation that touches nothing at all.
