# Mountain — alternate arts (saved for future reference)

The active card art is `../art.png`. The PNGs in this folder are **alternates only** —
they are NOT wired into the card and the engine ignores them (only `art.png` is loaded).
They are parked here as "commented out" options to swap in or revisit later.

These came out of the skill-eval A/B run for the mountain basic land. The chosen
`art.png` was the arbitrary pick among several near-equivalent vistas; these three
were liked enough to keep on hand. Each was generated at 64x32 via the pixellab
helper; `*_8x.png` is just an 8x preview of the same frame.
