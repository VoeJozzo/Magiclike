# Card back: source

`../card_back.png` is generated by `card_back.py` in this folder. To change the design, edit the script and rerun it:

```
python3 assets/card_back/source/card_back.py
```

**Design ("warp and weft"):** five warp threads in the house thread colors (ivory, cerulean, wine-purple, crimson, emerald, in WUBRG order) run the length of a deep-wine twill card. A gold weft passes over and under them inside a gold lozenge. It reads as "the weave" (see `docs/wiki/world/threads.md`) and stays neutral to all five colors.

**Size:** 80×112, the same as the card frames, opaque RGB. Scale it only by whole numbers with nearest-neighbor filtering, the same way as the frames.

**Origin:** first drawn procedurally in the board concept mockup (`docs/design/board-tapestry/`, `backPix()`). The script is a pixel-identical port of that function.
